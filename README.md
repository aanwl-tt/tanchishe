# 🐍 贪吃蛇 - 吃球大作战

一款功能丰富的贪吃蛇游戏，支持手机触控操作、关卡系统、皮肤自定义、存档导入导出。

## 📦 快速开始

1. 下载 `index.html` 文件
2. 双击文件在浏览器中打开（电脑/手机均可）
3. 开始游戏！

## 🎮 游戏玩法

### 基本规则
- 🎯 控制蛇移动，吃到球后蛇身会变长
- ⚡ 每吃 5 个球速度会略微加快
- 💥 撞到墙壁、自身或障碍物 → 游戏结束
- 📊 显示操作次数和理论最少操作数

### 操作方式
- **电脑**：方向键 ↑↓←→ 或 WASD 移动 | 空格键重新开始
- **手机**：滑动画面 | 点击屏幕下方方向按钮 | 点击画面重新开始

### 关卡系统
- 20 个关卡，难度逐级递增
- 关卡解锁机制：通过第 N 关后自动解锁第 N+1 关
- 每关包含不同数量的障碍物
- 过关需要吃到指定数量的球

## 🎨 皮肤系统

进入菜单 → **皮肤设置**，可自定义：

### 蛇身皮肤
- 调整图案长度（1-40 格）
- 用调色盘为每一格绘制颜色
- 选择预设颜色或自定义 RGB 颜色

### 球皮肤
- 从 18 种预设颜色中选择
- 支持自定义 RGB 颜色

### 背景皮肤
- 18 种预设背景颜色
- 自定义背景颜色（作用于页面空白区域）

## 💾 存档管理

游戏支持导出/导入存档，让你永远不丢失进度：

### 导出存档
1. 点击菜单的 **「📥 导出存档」** 按钮
2. 下载得到 `贪吃蛇存档.json` 文件
3. 保存好这个文件（电脑/网盘/微信传输均可）

### 导入存档
1. 点击菜单的 **「📤 导入存档」** 按钮
2. 选择之前下载的 `.json` 文件
3. 所有进度和皮肤设置自动恢复

### 存档包含的数据
- ✅ 已解锁的关卡进度
- ✅ 已通关的关卡记录
- ✅ 自定义的蛇身/球/背景颜色
- ⚠️ 浏览器 localStorage 也会自动保存（清除缓存会丢失）

## 📱 手机适配

游戏完全支持手机游玩：
- ✅ 触屏滑动控制方向
- ✅ 十字方向按钮辅助控制
- ✅ 画面自动适配屏幕大小
- ✅ 禁用页面缩放，防止误触

## 🔧 技术实现

- **技术栈**：纯 HTML + CSS + JavaScript（无任何外部依赖）
- **渲染**：Canvas 2D API
- **单文件**：所有代码包含在一个 HTML 文件中
- **兼容性**：支持所有现代浏览器（Chrome/Firefox/Safari/Edge）
